# light_system_cad

3D-printable enclosure for an ESP32-S3 based LED light controller, modelled in FreeCAD.
The whole model is generated by a single parametric Python script, so every dimension
can be changed and the case rebuilt in seconds.

Outer size: **116.2 × 65.4 × 39.1 mm** (base + screw-down lid).

## Components

| Component | Part | Mounting |
|---|---|---|
| Controller | ESP32-S3-DevKitC-1 | Rests on end supports with side guides; two USB-C openings in the end wall |
| Display | OLED 1.54" 128×64, 7-pin (SPI) | Under the lid, M2 self-tapping screws into bosses; chamfered viewing window |
| Input | Bourns PEC11R-4115F-S0018 rotary encoder with push switch | M9 bushing through the lid, printed knob with D-bore |
| Power supply | LM2596S 5 V buck module | Floor standoffs, M3 self-tapping |
| Power input | 5.5×2.1 mm DC panel jack, M8×1 thread | End wall |
| Power switch | SMRS-101 mini rocker | Snap-in cutout in the end wall |
| LED drivers | 2× IRFR120N (FR120N) MOSFET module | Floor standoffs, M3 self-tapping, one each side of the ESP32 |
| LED outputs | 2× Amass XT60E-F (female, panel mount) | Mounted externally on the long walls, M3 screws + nuts |

Other features:

- Lid fixed with 4× M3 countersunk screws into corner bosses, with a locating lip
- Ventilation slots on both long walls and in the lid
- Lid holes for the ESP32 BOOT / RST buttons and RGB LED
- Two keyhole slots in the bottom for wall mounting (92.2 mm apart)
- Recesses for Ø8 mm adhesive rubber feet

## Power wiring

```
DC adapter ─► DC jack ─► rocker switch ─┬─► LM2596S (5 V) ─► ESP32-S3 5V pin
                                        ├─► MOSFET 1 VIN ─► XT60 #1 ─► LED strip 1
                                        └─► MOSFET 2 VIN ─► XT60 #2 ─► LED strip 2
```

The LED strips run at the adapter voltage. Choose an adapter rated for both strips plus
the controller. MOSFET signal inputs go to two PWM-capable ESP32 GPIOs. When powering
the ESP32 through its 5V pin, check that your board revision has a diode between 5V and
USB before you plug in USB for programming.

| File | Description |
|---|---|
| `esp32s3_case.py` | Parametric build script (source of truth) |

## Rebuilding the model

Open FreeCAD and run in the Python console:

```python
exec(open("/path/to/light_system_cad/esp32s3_case.py").read())
```

Update the `OUT` path at the top of the script to your checkout location first. The script
rebuilds the document, checks every part pair for interference and re-exports the STLs.

All dimensions are parameters at the top of the script. Values marked **verify** are
typical figures for those parts. Measure your components and adjust them before
printing: the OLED, encoder, LM2596S and MOSFET module sizes and hole positions, the
switch cutout, the XT60E-F body, and the USB-C port spacing (`usb_dy`).

## Printing

Tested target: Bambu Lab printers (fits even the A1 mini).

- Material: **PETG** recommended (PLA OK for low loads, ASA for hot locations)
- 0.4 mm nozzle, 0.2 mm layers (0.16 mm for the knob), 4 walls, 15–20 % gyroid infill
- No supports needed for any part
- Base: floor on the bed. Lid: outer face on the bed. Knob: as exported
